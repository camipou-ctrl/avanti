# RE/MAX Avanti — app instalable

Pantalla de entrada e ícono para instalar el panel de RE/MAX Avanti en el teléfono o la computadora.
Aquí no hay código ni datos: la app abre por dentro el panel de Google Apps Script, que pide PIN.

- **Android (Chrome):** menú ⋮ → *Instalar app*.
- **iPhone (Safari):** Compartir → *Agregar a inicio*.
- **Computadora (Chrome/Edge):** ícono de instalar en la barra de direcciones.
